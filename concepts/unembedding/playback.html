Logit lens: guess per layer

One matmul back to vocabulary

Did you know?

Input and output tables are usually tied — the same weights transposed. So a logit is literally "how similar is the final state to this token's embedding".

In the real world

This head is ~10–30% of small models' parameters — the vocabulary × width matmul is no afterthought. For GPT-2: 50,257 × 768 ≈ 38.6M of its 124M params.

The stack ends with a $d$-d hidden state. The unembedding matrix scores it against every vocabulary row → logits → softmax → probabilities. One pass, one distribution, one sampled token.

The logit lens — the cheapest probe

Did you know?

Run layer-12's hidden state through the output head early and you often already see the answer — the model's guess crystallizes before the stack finishes. That trick (nostalgebraist, 2020) is free — it's why the panel can show "guesses per layer".

In the real world

Interpretability teams use tuned lenses — learned fixes to the raw head — to decode middle layers faithfully, e.g. reading when a model "decided" to hallucinate.

Because every sublayer writes into the same residual stream, any layer's state can be projected to vocabulary space. Watch the distribution sharpen layer by layer — that's the model "making up its mind" in public.

From scores to a choice

Did you know?

Temperature τ rescales logits before softmax: τ→0 collapses to greedy, large τ flattens toward uniform. Top-p keeps only the smallest set of tokens covering mass p — the "nucleus".

In the real world

Every "creativity" slider in a product is this paragraph: temperature for flatness, top-p/top-k for tail truncation, penalties for repetition — all downstream of the same logits. See inference.

Deterministic systems end here in a probability simplex — the only randomness in the model is the sampling step. Decode policy is a product decision layered on top of identical machinery.
