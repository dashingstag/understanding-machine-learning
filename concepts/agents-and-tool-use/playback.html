Agents and tool use

The loop, live

Model → agent

Did you know?

ReAct (Yao et al. 2022) noticed the trick first: interleave "thought" and "action" tokens and a text model becomes a controller — the thought is a scratchpad, the action is a tool call. Most of 2026's agent products are this pattern, scaled.

In the real world

Coding agents resolve GitHub issues, computer-use agents drive desktops, deep-research agents browse for an hour. The product isn't a completion — it's the loop.

A single completion is a function call; an agent is a control loop — perceive, plan, act, observe, repeat. The LLM is the component inside, not the system.

Acts are tool calls

Did you know?

Every tool call is just tokens: the model emits a JSON-shaped completion, a wrapper parses it, the world executes it, and the result re-enters context as more tokens. Agency is an I/O convention — details.

In the real world

MCP standardized the socket: one protocol, any tool server — file systems, GitHub, databases, browsers. The agent/tool market runs on it.

Search, code execution, file IO, APIs — each a schema'd function. The model chooses name + arguments; everything after is ordinary software.

The context is the state

Did you know?

An agent's "memory" is literally its context window — plans, tool results, errors all live as tokens. Compaction (summarize and drop) is garbage collection by prompt.

In the real world

Long-horizon tasks fill the window: the loop must decide what to keep — scratchpads, summaries, and RAG are the standard answers.

Each observation is appended; the model re-plans on the whole history. Reasoning traces (CoT) double as plans — thinking and acting share the same tokens.

Where loops break

Did you know?

A 95%-per-step agent has ~36% success over 50 steps — errors compound multiplicatively, which is why verifiable checkpoints and retries are the engineering, not an add-on.

In the real world

Prompt injection through tool results — a web page or email that hijacks the agent mid-loop — is the defining security problem of the agent era. See safety.

Non-termination, tool hallucination, compounding error — agent reliability is mostly loop engineering, not model quality. Benchmarks like SWE-bench score the *system*, model included.
