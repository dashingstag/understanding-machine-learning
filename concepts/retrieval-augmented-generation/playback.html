The RAG pipeline

Weights vs shelves

Did you know?

Patrick Lewis's 2020 paper coined the term — the insight was that a parametric model's memory is a blurry photocopy; giving it a shelf of documents made knowledge-intensive QA suddenly work.

In the real world

Enterprise "chat with your data" is 90% this pipeline — plus a system prompt and a citation template. Your docs were never in the weights; the index is the product.

A model's knowledge is frozen at training and private data was never there. RAG answers both: retrieve the real document at question-time, let the model read it like you would.

Index: chunk, embed, store

Did you know?

Chunking is the unglamorous step that decides everything: split a table mid-row and the answer becomes unreachable — no downstream step can recover what was never a whole unit.

Corpus → chunks (~300–500 tokens, overlap) → each gets an embedding → ANN index (vector search: HNSW/IVF). Offline, once — this is the "shelf".

Retrieve: what the model gets to see

Did you know?

Lost-in-the-middle means where a chunk lands in the context matters: models use the edges best — so reranking puts the winner first, not buried at #7.

In the real world

Retrieval misses — the right chunk never fetched — are the dominant RAG failure in production. Hybrid BM25+vector and a reranker are the standard band-aid.

Query → same embedder → top-$k$ by cosine → rerank → stuff into the prompt. The retrieved set bounds every claim the model can possibly make — the context *is* the knowledge.

Cite, or it didn't happen

Did you know?

Grounded hallucination becomes checkable: the answer names its source chunks, so a wrong answer means either bad retrieval or a model that ignored its own evidence — two different bugs with different owners.

In the real world

The failure taxonomy in production: retrieval miss > context dilution > model error > index staleness — in that order. The model is usually the *least* guilty part.

The generation step is ordinary LM decoding — the magic is entirely upstream, in what the context contains. Agentic variants let the model decide when and what to fetch — the pipeline dissolving into a tool call.
