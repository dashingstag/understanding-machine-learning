The pipeline

From text-completer to assistant

Did you know?

Paul Christiano's 2017 "Deep RL from Human Preferences" laid the whole scheme out five years before InstructGPT made it famous — same idea, tiny models.

In the real world

Post-training is ~1–5% of total compute but ~90% of perceived product quality — the stage where "a model" becomes "a brand".

A pretrained model completes text — prompts included. It can't follow instructions, has no refusals, and absorbed the whole internet's tone. The pipeline on the right is how it becomes an assistant.

Stage 1 — imitation

Did you know?

A few thousand curated demonstrations can install chat format on a 70B base — SFT is shockingly sample-efficient because capability already exists; only the interface is missing.

Supervised fine-tuning: imitate expert demonstrations — instruction → ideal response. Same `cross-entropy` machinery, new distribution: format, tone, "as an AI" boundaries all arrive here.

Stage 2 — learn what 'better' means

Did you know?

Human raters rank pairs of completions — cheaper and more consistent than absolute scores. Bradley–Terry turns rankings into a scalar reward model.

In the real world

Goodhart: the moment the reward model is optimized, it stops being a good measure — reward hacking, sycophancy and verbosity bias are all this one law at work.

Humans can't score millions of samples, so a model learns the ranking instead — then RLHF pushes the policy up that learned gradient, `rlhf-obj`.

Stage 3 — optimize: PPO or DPO

Did you know?

DPO (Rafailov et al. 2023) derives the same preference optimum closed-form: the reward model cancels out and alignment becomes a supervised loss on pairs — now the default in open models.

PPO: sample responses, score with the RM, ascend with a KL leash to the SFT policy. DPO: skip sampling entirely — `dpo-loss` directly re-weights log-probs of chosen vs rejected. Same destination, different machinery.

The new stage — RL where answers check

Did you know?

Math answers and code tests grade themselves — so RL can use ground truth instead of a learned reward. That switch, scaled, is what produced reasoning models.

In the real world

GRPO-style group baselines replaced PPO's value network in this regime — the recipe behind DeepSeek-R1 and the 'thinking' mode in every 2025+ frontier model.

Verifiable rewards close the loop where reward models fail: no hacking a unit test. The frontier pipeline now ends here, not at preference RL.
