Superposition → features

We ship systems we can't audit

Did you know?

Chris Olah built Anthropic's interpretability program on a wager: if you can find real features inside the model, alignment becomes engineering instead of hope.

In the real world

Frontier models make legal, medical and financial claims — with internals nobody can read. Interpretability is the only field asking "what did it actually compute?" instead of "what did it output?"

Everything else on this map asks what a model does. This page asks what it is: which directions in which layers mean "this is a request to hack something" — and whether such directions exist at all.

Why neurons can't be read

Did you know?

One neuron fires for French text, Python syntax and open parentheses — models pack more concepts than they have neurons by storing features in overlapping directions: superposition.

The naive approach — name each neuron — died immediately: individual units are polysemantic. The fix is sparse autoencoders: learn a bigger dictionary in which features are single-purpose — the panel shows soup separating into features.

The instruments: probes, lenses, circuits

Did you know?

Induction heads — attention heads that copy "[A][B] … [A] → [B]" — were causally verified as in-context learning's mechanism (Olsson et al. 2022): ablate them and ICL collapses. Proof that real mechanisms exist.

In the real world

Probing asks "does layer N encode X?" (cheap, correlational); the logit lens asks "what would the head say now?"; circuit analysis asks "which parts compute it?" — three instruments, three different claims.

Correlational instruments (probes) map where information lives; causal instruments (ablations, patches) test whether it's actually used — the distinction that makes a finding real.

Steering: interpretation you can push on

Did you know?

Anthropic's "Golden Gate Claude" added a found feature's direction to every forward pass — the model answered every question about the Golden Gate Bridge. Absurd, and proof that features are levers: activation steering.

In the real world

Safety uses: honesty/sycophancy directions, deception detection, unfaithful-CoT alarms — reading the machine is the audit; editing it is the control. Both ride on the residual stream.

The causal test of a claimed feature: does pushing it change behaviour? If yes, the feature is a mechanism, not a correlation — and potentially a control.
