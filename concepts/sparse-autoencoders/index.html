Sparse autoencoders

MapNotes

Dictionary learning over activations — the tool that turned neuron soup into named, steerable features.

Statement

Dictionary learning over a model's activations: train an autoencoder with a bottleneck wider than the input and a sparsity penalty so that each hidden unit captures one feature — decomposing superposed embed-e-space directions into nameable, steerable features. The workhorse that turned interpretability from neuron-reading into feature-finding (Cunningham et al.; Templeton et al. "Scaling Monosemanticity").

In my own words

One paragraph, as few symbols as possible. Written by me, not copied.

Why the parent needs it

interpretability — neurons are polysemantic (French + code + parens in one unit); SAEs disentangle the soup into a bigger sparse basis where features are single-purpose — the prerequisite for activation-steering and feature-level auditing.

Teardown

  1. Architecture. Encoder: activations → wide sparse layer ($\mathrm{ReLU}$ or TopK); decoder: features → reconstructed activations. Loss = reconstruction + sparsity penalty.
  2. Superposition fix. The model packs $F$ features into $d < F$ neurons; the SAE unpacks them back into ~$F$ dictionary atoms — each atom hopefully one concept.
  3. Naming. Features are labeled by inspection: max-activating examples + automated explanations — "Golden Gate Bridge feature" became the field's mascot via activation-steering.
  4. Scale. Anthropic's 2024 runs: millions of features across mid-stack layers of Claude — hierarchical: features split into finer sub-features as the dictionary grows.
  5. Open problems. Feature splitting/merging instability, dead latents, missing the computational role (a feature exists ≠ the model uses it), SAE-vs-transcoder debates for circuits.
