One trunk, many doors

One model, many senses

Did you know?

Alec Radford's CLIP (OpenAI, 2021) proved one contrastive objective could align 400M image–text pairs — the backbone most multimodal systems still stand on.

In the real world

GPT-4V, Gemini, Claude — frontier products are natively multimodal. The text stack didn't change; the input pipeline grew doors.

Text, image, audio, video — each becomes a sequence of vectors through a modality tokenizer, then the same transformer trunk processes the mix. Cross-modal reasoning is just attention over a mixed sequence.

How pixels become tokens

Did you know?

ViT chopped images into 16×16 patches and treated them as words — "an image is worth 16×16 words" is literally the paper's subtitle (Dosovitskiy et al. 2020).

In the real world

~576 image tokens ≈ a paragraph of text — so a screenshot costs the context window of a page of prose. Image token budgets are why long-video understanding is still expensive.

Patches, VQ codes, spectrogram slices — every modality is made legible the same way: cut it up, embed each piece, hand it to the trunk. The model never sees pixels; it sees $d$-dimensional tokens.

How the senses agree

Did you know?

Contrastive learning needs no labels — an image and its caption are a free positive pair. 400M web-scraped pairs built the space CLIP lives in.

Understanding needs shared meaning: pull matching image/text embeddings together, push mismatches apart. That pre-aligned space is what an LLM's projector plugs into — the vision encoder arrives already speaking "meaning".

Same trunk, motors attached

Did you know?

RT-2 (Google DeepMind) fine-tuned a vision-language model to emit robot action tokens — the same network that describes an image can move an arm, because actions are just another vocabulary.

In the real world

VLA models (RT-2, π0) drive real robots; self-driving stacks are the same architecture with different output heads. The output side needs modality decoders: diffusion for pixels — next page.

Understanding reuses the LM head; action and generation need modality-specific outputs — diffusion for images, codec decoders for audio, action tokens for robots.
