A token's climb up the stack

The pipeline

Did you know?

Ashish Vaswani's 2017 paper was titled as a provocation — "Attention Is All You Need" — and the provocation won: within five years RNNs were effectively extinct at the frontier.

In the real world

GPT, Claude, Gemini, Llama, Grok, DeepSeek — every frontier text model is this stack. Size, training and sparsity differ; the block diagram does not.

Text in $\to$ tokens $\to$ vectors $\to$ $L$ identical blocks $\to$ vocabulary scores. Every block does exactly two things: mix across positions (attention), then transform each position (FFN).

Anatomy of one block

Did you know?

The residual stream — the model width-sized highway each sublayer reads and writes — is also what makes mechanistic interpretability possible: you can read the draft, not just the final answer.

Two sublayers, each wrapped the same way: normalize, compute, add back to the stream. The layer normalization + residual pattern is the plumbing that keeps gradients alive through 100+ layers — torn down separately.

Mix across positions, transform each one

Did you know?

Attention is the only place tokens exchange information — and it costs $\mathcal O(n^2)$ in context length (see the result). That single term shapes KV caches, context windows and serving prices.

In the real world

Parameter split inside a block is roughly ⅓ attention, ⅔ FFN. The FFN is where most factual knowledge is believed to live — attention is more like routing hardware.

Attention answers "who should I look at?"; the feed-forward layer answers "given what I gathered, what do I become?" Neither works alone — pure attention just averages, pure FFN can't see context.

Out the top: the unembedding

In the real world

The output head is often literally the input table transposed — 'weight tying'. So a token's logit is an inner product between its embedding and the final hidden state: the model scores candidates by similarity.

The last hidden state meets the unembedding matrix → logits → softmax → a distribution over vocabulary items. Sampling under temperature (or top-p/top-k) is the only randomness in the whole system — see the head page.

Why this architecture won

Did you know?

The bitter lesson (Sutton): methods that leverage compute beat methods that leverage human knowledge. The transformer is the architecture most optimized for being scaled — which is why scaling laws are its biography.

In the real world

Everything is a matmul, a softmax or a norm — three GPU-shaped primitives. Distributed training loves it; a trillion-parameter variant is the same code with bigger shapes.

No recurrence → perfect parallel training. Residual paths → constant-length gradient routes. Homogeneous blocks → hardware-simple. The architecture wasn't proven better — it was built to scale, and scale won.

Challengers exist — state-space models, linear attention — torn down under inference efficiency.
