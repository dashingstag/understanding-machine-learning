Loss curve of a frontier run

The whole recipe in one line

Did you know?

Ilya Sutskever bet a decade on "predict the next token" before it looked like intelligence — GPT-2's unsupervised multitask claim was the first proof the bet paid.

In the real world

A frontier run is ~$10^{25}$ FLOPs, ~$10^{13}$ tokens, weeks of calendar time, eight figures of compute spend — all for this single loss term.

Predict the next token, at every position, on the whole curated internet. `cross-entropy` measures the miss; gradient descent walks it down. No labels, no tasks — the corpus supervises itself.

What $6ND$ buys

Did you know?

The Chinchilla scaling law (Hoffmann et al.) showed most big models were under-trained, not under-sized: the compute-optimal recipe is ~20 tokens per parameter — the reason Llama-7B saw a trillion.

Each parameter does ~6 FLOPs per token: 2 forward, 4 backward. `compute-c` is therefore set by `n-params` × `data-d` — and scaling laws predict the final perplexity before the run starts.

The corpus is the curriculum

Did you know?

Models trained on deduplicated, filtered data beat ones trained on raw scrapes at the same size — data quality is worth parameters. "The Pile" (Gao et al.) made that curation public and set the open-source standard.

In the real world

The mixing ratio — how much code vs math vs web — is a guarded lab secret and a live contamination surface: test sets leaking into scrapes inflate scores silently.

Trillion-token corpora are built, not found: dedup, quality classifiers, toxicity filters, per-domain weights, and increasingly synthetic data written by earlier models — the curation node.

Running it without dying

In the real world

Loss spikes at 3 a.m. are routine: a batch of bad data, an LR bump, a flaky interconnect — mitigation is checkpoints, clipping, rollbacks, and a war room. This is what distributed training operationalizes.

The panel's curve is stylized but honest: sharp early drop, long power-law tail, a spike or two where something broke and got rolled back. AdamW, warmup + cosine decay, gradient clipping — the boring machinery that makes the headline model possible.

What actually gets learned

Did you know?

Capabilities like 3-digit arithmetic appear near-abruptly with scale (emergent abilities, Wei et al.) — though later work showed some "emergence" is a metric artefact. Both claims live in evaluation.

Order of appearance: byte statistics → grammar → facts → multi-hop patterns → latent reasoning scaffolding. Everything post-training does is reshaping what already exists here — which is why base-model quality gates the whole pipeline.
